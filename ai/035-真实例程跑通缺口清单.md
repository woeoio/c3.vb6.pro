## 3. 剩余缺口（按阻塞面排序）

### 3.1 `Set Adodc1.Recordset = rs`（5 处，架构性）

生成 `vb6_Adodc_Recordset(hwnd) = rst;` —— 读侧函数不是左值，C2106。

根因不是漏个 setter：Adodc 的 Recordset 是**内部引擎派生**的只读出口
（`vb6_Adodc_Recordset` → `adodcEnsureEngine` → `vb6_Data_RecordsetObj`），
而 `check_data_recordset_shape.ps1` 又把"recordset 成员面只有一套答案"钉死。
要支持外部 Recordset 注入，得先决定：**Adodc 是否允许挂外部 Recordset**，
以及挂上之后 DataGrid 走哪条渲染路径（现在是 `vb6_Adodc_Engine`）。
这一条与 C30-5 挂账的"运行期 `Set DataGrid1.DataSource = Adodc1`"是同一族，应一起做。

### 3.2 Variant → 标量（23 处，cgen 类型收口）

四种站点：

```
int32_t rown_end = rowcount1;                     // For 的终值（rowcount1 无类型 ⇒ Variant）
len1 = vb6_VarAddV(i, vb6_VariantFromValue(1));   // 目标 int16_t，右值 VARIANT 结构体
vb6_AddItemAt(hwnd, text, i);                     // 形参 int32_t，实参是 Variant 变量
```

`vb6_VariantFromValue` 的 `_Generic` 已经有 `vb6_VARIANT → vb6_VariantIdentity` 一档，
所以不是装箱问题，而是**出箱**：目标为整型时没套 `vb6_VariantToLong`。
`cgen_assign_prop_write.inc:589` 有先例（控件属性写），这里要覆盖到
局部变量赋值 / For 终值 / 方法实参三处。

### 3.3 其他（4 处）

`MsgBox`、`vb6_BSTR_AssignMove` 的实参个数/形态 —— 单独看，各自是一两行的事。

## 4. 复跑方法（判据口径）

```powershell
# 1) 清掉旧日志（C3 的 c3-error.log 是追加的，不清会把上轮的错误算进来）
Remove-Item .build\real1\c3-error.log -ErrorAction SilentlyContinue
# 2) 编
.build\C3.exe "<vbp 绝对路径>" --output-dir .build\real1
# 3) 按错误码聚类（GBK 日志）
$b=[IO.File]::ReadAllBytes((Resolve-Path .build\real1\c3-error.log))
([Text.Encoding]::GetEncoding(936).GetString($b) -split "`r?`n" | ? { $_ -match ': error ' }) |
  % { if ($_ -match 'error (C\d+):') { $matches[1] } } | Group-Object | Sort-Object Count -Descending
```
