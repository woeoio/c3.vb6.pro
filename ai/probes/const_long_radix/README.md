## 要回答的一问

**同一个字面量落在 `As Long` 的类型上下文里，VB6 交的是按值加宽还是按位加宽？**

| 写法 | 按值加宽（我们现在发的） | 按位加宽 |
|---|---|---|
| `Const M As Long = &H8000` | `-32768` | `32768` |
| `Const M As Long = &HFFFF` | `-1` | `65535` |

**Why it matters**：真语料里有 **58 处** `Const … As Long = &Hxxxx` 落在这档
（czUI 的 `MEM_RELEASE`、`DT_END_ELLIPSIS`、`CLR_INVALID`、`H_MAX = &HFFFF + 1`、
`Optional ToPage As Long = &HFFFF` …）。两档答案对这 58 处的**运行期读数**不同 ——
典型是交给 Win32 API 的那个 32 位掩码会不会被高 16 位的 `FFFF` 污染。
