# MaskEdBox 控件（掩码编辑框）

> 部件：Microsoft Masked Edit Control 6.0 (SP6)，MSMASK32.OCX

## 1. 概述
带"输入掩码"的文本框：用掩码字符串规定每一位允许输入什么，
非法按键直接被拒绝，适合电话、日期、编号、车牌等**固定格式**录入。

## 2. 主要属性

| 属性 | 说明 |
|---|---|
| `Mask` | 掩码字符串（核心），字符含义见 §3 |
| `Text` | 控件文本（含掩码中的固定符号与提示符，受 PromptInclude 影响） |
| `ClipText` | **只含用户实际输入的字符**（去掉固定符号与提示符）——存库请用这个 |
| `PromptChar` | 空位提示符，默认 "_" |
| `PromptInclude` | 决定 Text 是否包含提示符与固定符号 |
| `SelStart / SelLength / SelText` | 选区操作 |
| `ReadOnly / Enabled / BackColor / ForeColor / Font / BorderStyle` | 常规属性 |

## 3. 掩码字符表

| 字符 | 含义 |
|---|---|
| `0` | 数字 0-9，必填，不接受正负号 |
| `9` | 数字或空格，可选 |
| `#` | 数字、空格或正负号，可选 |
| `L` | 字母，必填 |
| `?` | 字母，可选 |
| `A` | 字母或数字，必填 |
| `a` | 字母或数字，可选 |
| `&` | 任意字符，必填 |
| `C` | 任意字符或空格，可选 |
| `. , : ; - /` | 日期/时间分隔符（按系统区域显示） |
| `<` / `>` | 其后字符强制小写 / 大写 |
| `\` | 转义：把下一个字符当普通符号显示 |

## 4. 事件
无专属事件：Change、Click、DblClick、GotFocus/LostFocus、
KeyDown/KeyPress/KeyUp、MouseDown/Move/Up 等常规事件。
（格式校验由掩码在按键级自动完成，无需自己写校验。）

## 5. 示例

```vb
MaskEdBox1.Mask = "(999) 000-0000"     ' 电话：区号可选、号码必填
MaskEdBox2.Mask = "00/00/0000"         ' 日期
MaskEdBox3.Mask = ">LLL-000000"        ' 如 ABC-123456，字母自动转大写

' 存库 / 回显
rs!电话 = MaskEdBox1.ClipText          ' 只存用户输入的数字
MaskEdBox1.Text = rs!电话              ' 回显时自动套上掩码格式
```

> 坑：掩码是**定长**的，长度可变的输入（如姓名、地址）请改用 TextBox + LostFocus 校验；未填满时 ClipText 可能含空格，存前 Trim 一下。

## 6. C3 的实现与口径（C30-3，2026-11-15）

落点：**Win32 的 `EDIT`** + `src/rtl/core/vb6forms/vb6forms_maskededit.c` 一层掩码状态机（不加载 MSMASK32.OCX）。

### 6.1 编辑模型

显示串**恒为一位掩码一位字符**（固定符号 / 用户字符 / 空位提示符），所以
“显示下标 == 掩码位下标”这条恒等式成立 —— 光标与选区换算不用再查表。
键盘输入全部在 RTL 子类里吃掉、不交给 EDIT 自己插：EDIT 不懂掩码，交出去就会出现
固定符被退格删掉、字母被插进数字位这类串味。

### 6.2 掩码字符表（逐条立，与 §3 一一对应）

`0` / `9` / `#` / `L` / `?` / `A` / `a` / `&` / `C` 九档按位校验；`<` `>` 是**状态量**
（影响其后所有输入位，不是一次性）；`\` 只作用于紧随的一位；其余字符（含 `. , : ; - /`）
一律当固定符号。

### 6.3 属性口径

| 属性 | 口径 |
|---|---|
| `Text` | 含固定符号；`PromptInclude=True`（默认）时还含空位提示符 |
| `ClipText` | 只含用户实际输入的字符（不含固定符号与提示符） |
| `Mask` | 回读**原样**掩码串（未解析的那一串） |
| `PromptChar` | 单字符，默认 `_`（VB6 里是 String 型，这里同样收 BSTR） |
| `PromptInclude` | Boolean，默认 True |
| `SelStart/SelLength/SelText` | 显示坐标（固定符也占位），沿用编辑控件那三条通用出口 |

赋值规则：`Text =`（以及 `ClipText =`）会把串按掩码**逐位对位**：走到固定符位时，
若串里这一位正好等于该固定符就吞掉它（所以带格式的回显也认）；一个字符在当前位置
收不了时，**继续找后面第一个能收的输入位**，全都不收则丢弃它且不推进掩码。

### 6.4 实跑读数（`tests/ctrlmaskedbox`，x64 与 x86 逐字一致，`exit=0`）

```
MK1-date=31/12/2025|31122025|00/00/0000   Text/ClipText/Mask
MK2-bad=12/34/____|1234                  非法字符不落盘
MK3-phone=(010) 123-4567                 固定符 + 可选位 9
MK4-upper=ABC-123456                     > 强制大写
MK5-lower=ab                             < 强制小写
MK6-opt=_5                               ? 可选字母（5 让给后面的 0）
MK7-sign=+7                              # 接受正负号
MK8-esc=A7                               \ 转义成固定符
MK9-any=a#                               & 任意字符必填
MK10-prompt=**                           PromptChar
MK11-noincl=|0                           PromptInclude=False（Text 不含提示符）
MK12-clip=01/01/2026                     ClipText 回灌带格式 Text
MK13-sel=31|0                            SelStart/SelLength/SelText
```

### 6.5 未覆盖（诚实口径）

1. **掩码里的日期/时间分隔符不随区域设置改写**：文档 §3 说 `. , : ; - /` 是“按系统区域显示”，
   这里一律按字面绘制。真要跟区域走，得引 `GetLocaleInfo` 的一层渲染映射，另开一刀。
2. **`ValidationError` 事件不实现**：非法按键被**静默拒绝**（不落盘、不响铃、不抛事件）。
   VB6 那侧会在失焦时对未填满的必填位弹错误；C3 目前没有运行期错误面，宁可不做。
3. **`AllowPrompt` / `AutoTab` / `MaxLength` 未单独接**：前三者的语义（提示符可被选中 /
   填满自动跳下一个控件 / 长度上限）在掩码定长下基本冗余；需要时另立一格。
4. **粘贴是逐位覆写**：不做“整串校验失败就整段拒绝”，与按键逐位落盘的口径一致。
