## 0. 这一格要买什么，不买什么

**要买**：`Dim r As K` + `Set r = New K` 这种最普通的写法，今天**每调用一次泄一枚实例**（实测 x64 ≈236 B/次、x86 ≈216 B/次，`.build/k868_{x64,x86}_run.txt`）。真语料的站点 = 过程级对象槽 **2822 处**，其中具体类档 **2775**（§B218 第四件量；大头 PhotoDemon 一份工程）。VB6 的口径 = 过程返回就放手自己的局部对象引用，没人接就当场 `Class_Terminate` + 还原内存。

**要买的那一句**：让「这枚工程类实例现在有几处握着它」在**类型里就有答案**（结构体头部那枚 `int32_t __refcount`），并且**只有一位主人**会加减它。

**不买**（写清楚，别混进本刀）：
- **环**（`a.parent = b` + `b.child = a`）：引用计数天生回收不了，VB6 也一样 —— 本方案不假装解决，落地后仍是已知边界。
- **带权临时量与 `For Each` 循环变量没人回收**（§B164 / 任务 #352）：另一族站点，另开。
- **512 格工程类登记表接读者**（§B187，出路 (a)/(b) 仍待拍）：与本刀无关。
- **`SingleUse` / `GlobalSingleUse` / `PublicNotCreatable` 那一族**：见 §1.4 —— 那三档今天**从没被 parser 认过**，压根没有"Instancing 造的隐藏实例"这一形，所以不欠它一条腿（这条**订正** §B218 待拍清单里那句「`SingleUse`/隐藏全局实例」。

## 2. 方案

### 2.1 一句话

把 B05 那枚 `int32_t __refcount` 从"实现新式接口的类"扩到**每个类模块**，并把今天**散在三处**的计数公式（AddRef 桩、Release 桩、claim 桩）收成**每类一枚的出入口**；五条腿（`New` / 覆写 / 置空 / 过程出口 / 包装器那两腿）从此**只调这一对**，谁也不许自己写 `+= 1`。

### 2.2 布局那一刀（改动面）

`emitIfaceClassFields`（`:382-393`）与 `emitIfaceNewInit`（`:395-405`）里那两句 `if (ifaces.empty()) return;` 改成"**头照发**，没接口的类到此为止"：`__refcount` 排在 `__comObj` 之后（`:387` 现位置，第 0 格不动 = D19），`__iv_<I>` 槽与 `.vt` 初始化照旧按 `ifaces` 循环。

机械安全性三条读数（§B218 第六件量，前两条我复算过）：
1. 产物里**没有裸偏移走法**：`k903_emit.txt`/`k927_emit.txt` grep `(char *)x ± 数字` = 0；发码那几处全让 C 自己算 `offsetof(<结构体>, __iv_<I>)`（`cgen_iface_vtbl.cpp:436/482/529/623`）⇒ 中间插一枚字段不需要改任何发出去的数。
2. RTL 只碰实例第 0 格：`ppComObj = (void**)instance` 那个约定写在 `vb6comserver_obj.c:487-489`（「前置条件：实例结构体首字段必须是 `__comObj`」）与 `vb6comserver.h:111` —— 头插在它**之后**。
3. 类型库里没有 per-instance 字段偏移（我们交出去的属性全是 `VAR_PROPERTY`，`VAR_PERINSTANCE` 只出现在读外部库那一路）⇒ 布局不会被写进任何持久格式。

⚠ x86 那一半门拿不到（`.github/workflows/ci.yml:83` 只跑 x64）⇒ **46 份含类工程本机 x86 真编真跑**是本刀必付的判据（两架构 padding 不同形）。

### 2.3 一处权威 = 一枚出入口

新增**一枚** RTL 出口（不是每条腿 inline 一遍）：

```c
void vb6_ClassRelease(void** slot, void (*destroy)(void*));
/* 空槽直接回；先清槽再退计数；退到 0 且 __comObj == NULL ⇒ destroy(me)；
   退到 0 但 __comObj != NULL ⇒ 不 destroy（着陆权在包装器，沿用 :498 那条现规则）。 */
```

为什么必须是函数而不是 inline 三行：这条判断有**四个分支**（空槽 / 还有引用 / 被包装器接管 / 真该拆），inline 五处 = 又造出五位主人（本线反复栽的那族：#167/#231/#245/#298/#443）。**先清槽再退**是刻意的：拆完之后槽里不能留野指针。
`claim` 那一腿对称：发码侧一处出口 `emitClassClaimExpr(inst)` 发 `((vb6_cls_X*)v)->__refcount += 1;`（类型名在手 ⇒ 不需要 RTL 函数），**站点数由哨兵钉**。

> ⚠ 落地第一件量：`vb6_ClassRelease` 这枚新 RTL 出口要走 `check_rtl_embedded` 那 125 份的规矩 + `c3rtl.rc` 的 touch 注释（整块 `/* */`，`#` 起头会让 rc.exe fatal C1021）。

### 2.4 一张登记面（取代"具体类压根没登记面"）

今天"这枚槽出口要不要放手"只有 ivref 一档有答案。本刀**不开第二条出口腿**，把 `ivrefLocalsToRelease_` 扩成带种类的一张表：

```cpp
struct SlotRelease { std::string expr; bool isView; /* + 具体类时带上类名，用于 mint destroy 指针 */ };
std::vector<SlotRelease> slotsToRelease_;   // 改名，取代 ivrefLocalsToRelease_
```

出口那一腿（`emitIvrefScopeRelease` → `emitScopeRelease`）按档各发一条：ivref 档**产物一字不动**（`s->vt->Release(s)`），具体类档发 `vb6_ClassRelease((void**)&x, (void(*)(void*))vb6_cls_X_Destroy);`。
**注册者只许两处**：局部声明（`cgen_localdecl.cpp`，紧邻 `:322-326` 那条 ivref 支）+ §2.5 腿④的返回槽夹。**注册前先过那道夹**：`expr == currentReturnVar_` 就不注册（把 `cgen_decl_func.cpp:398-409` 那条接口专用的夹提成两档共用的一句 —— 这是本刀"归一"的那一半）。

### 2.5 五腿（每腿一句"谁放手"）

| 腿 | 今天 | (甲) 之后 |
|---|---|---|
| **① New** | `visit(NewExpr)` 交一枚 = 1 的实例，落槽裸拷贝 | **计数初值不变（= 1）**；口径沿用 `:399-400` 那句「`_New` 交出的那一次引用由**创建者**持有」—— 变的只是"创建者从此要放手" |
| **② 覆写** `Set a = b` | `a = b;`（§1.1 行 202/204） | 收成一处 `emitClassSlotSet`：**先 claim(新) 再 release(旧)**（顺序照 QiSet `:735-740`，避免 `Set a = a` 把自己拆掉）；右侧就是 `New` 那一条时**不 claim**（工厂那一枚 1 正是给它准备的） |

## 3. 待用户拍板的一句（其余可照 §2 直接开工）

**P1 = 「一枚工程类引用交给别人时，谁握着」。** 今天两个形状各答一半，实物是：

- 局部之间：`Set b = a` = **裸拷贝、两边都不放手** ⇒ 计数头一上，同一实例就被两枚槽各退一次 ⇒ double free。**这一半 (甲) 靠腿②补 claim 就自洽**（先握新再放旧）。
- 交给**别人**的三条边：**实参**（`Take a`）、**进 Object/Variant 槽**（`Set v = a`）、**工厂返回**（`Set c = MakeOne()`）。这三条今天也全是裸拷贝、也不放手 ⇒ 现在"恰好不错"，因为**没人退数**。上了计数头，每条边都必须回答"交出去的是移交还是复制"。

推荐口径（= 与接口那一族今天已有的答案同形，改动面最小）：**移交只发生在 `New` 与"返回值交给调用方"这两处，其余三条边一律 claim 一枚**：

| 边 | 推荐 | 为什么 |
|---|---|---|
| 实参 `Take a`（`ByVal a As C`） | **claim**，被调方形参在出口放手 | 与 `emitIvrefQiSet` 的"槽里那枚引用归槽"同口径；不 claim 的话被调方里 `Set p = Nothing` 会拆掉调用方还在用的那枚 |
| 进 Object/Variant 槽 | **claim**（沿用腿⑤(c)），槽清空那腿放手 | 今天 #443 那条已经"把 `New` 的 +1 就地交给槽"—— 只有"值来自别处"的边需要 claim |
| 工厂返回 `Set c = MakeOne()` | 返回槽**不放手**（夹）+ 调用方落槽时**不 claim**（= 移交） | 这就是 §1.3 那条 `cgen_decl_func.cpp:398-409` 现成的夹，扩一档即可 |

（停在 P1 这一句上，不是停在这份方案：§2 的其余部分不需要新口径。）
